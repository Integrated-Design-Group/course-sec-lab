# 16 · 漏洞清单与验证方法（课程内网全量靶场）

> **适用对象**：课程小组成员、验证执行人、指导教师
> **前置条件**：已阅读 [07-security-isolation.md](./07-security-isolation.md)、[08-vuln-design.md](./08-vuln-design.md)；仅限课程授权环境
> **预计耗时**：通读 20 分钟；逐项复现 40～60 分钟
> **验证方式**：按本文逐项执行；结果与判定见第 4 节；不得对非本项目目标测试

## 0. 当前部署模式

- 分支：`vuln/ALL`（课程内网全量靶场，**不合并 main**）。
- 默认：`VULN_MODE=ALL`，5 个漏洞同时开启。
- 当前服务器：已部署 `vuln/ALL`，`health.vulnMode=ALL`，入口 `http://{{PUBLIC_IP}}:8080`。
- `main` 仍是安全基线，不含漏洞代码。
- 可用 `VULN_MODE=off | VULN-01 | VULN-02 | VULN-03 | VULN-04 | VULN-05 | ALL` 切换；默认 `ALL`。
- 仅课程内部使用；演示账号 `admin` / `student`（密码 `Demo@123456`）暂保留，公网暴露风险由课程负责人确认。
- 验证后应恢复 `VULN_MODE=off` 或停止实例；主站当前按要求保留运行。

> 本文只描述验证思路与判定，不提供可直接复用的完整攻击载荷；具体输入应在授权靶场内按最小影响原则构造，且不得写入公开渠道。

## 2. 逐项设计、影响与修复

### VULN-01 · 登录 SQL 注入 / 认证绕过

| 项 | 内容 |
| --- | --- |
| 受影响角色 | 未认证访问者 |
| 前置条件 | `VULN_MODE=ALL` 或 `VULN-01`；MySQL 驱动；存在演示账号 |
| 成因 | 登录名/邮箱被直接拼接到 `users` 查询；检测到注入语法时跳过 bcrypt 密码校验 |
| 预期影响 | 使用构造的登录名**无需正确密码**即可登录为查询返回的第一个用户（通常为 admin）；可读取该账号可见数据 |
| 检测方法 | 对比正常错误密码（401）与注入型登录名（200 + admin 角色）；观察 `auth.login` 审计 |
| 修复建议 | 全部参数化查询；登录查询与密码校验分离；失败统一返回；最小权限数据库账号；WAF/告警 |
| 当前状态 | 已验证：注入登录 200 admin；正常用户名+错误密码仍 401 |

### VULN-02 · 条目描述存储型 XSS

| 项 | 内容 |
| --- | --- |
| 受影响角色 | 浏览条目的学生/管理员 |
| 前置条件 | `VULN_MODE=ALL` 或 `VULN-02`；学生可写描述 |
| 成因 | 后端在 ALL/VULN-02 时不再转义描述；详情页按 HTML 渲染 |
| 预期影响 | 受害者打开详情页时执行事件型脚本，可窃取会话/篡改页面 |
| 检测方法 | 用测试账号写入带事件属性的 HTML；用另一账号/浏览器打开详情页，观察脚本标记是否执行 |
| 修复建议 | 输出编码；CSP；富文本白名单；HttpOnly Cookie；不直接使用 `dangerouslySetInnerHTML` |
| 当前状态 | 已验证：off 转义不执行；ALL 下 Edge headless `window.__xss=1` |

### VULN-03 · 业务条目水平越权（IDOR）

| 项 | 内容 |
| --- | --- |
| 受影响角色 | 已登录学生 |
| 前置条件 | `VULN_MODE=ALL` 或 `VULN-03`；存在他人条目（如 admin 的 id=5） |
| 成因 | 写操作跳过 `owner_id` 归属校验（管理员仍放行） |
| 预期影响 | 学生可修改/删除他人条目 |
| 检测方法 | 学生令牌 PATCH 他人条目：off 403；ALL 200，owner 不变 |
| 修复建议 | 服务端每次校验 `owner_id`；管理员显式授权；403 |
| 当前状态 | 已验证：off 403；ALL 200 |

### VULN-04 · 不安全文件上传 + 公开读取

| 项 | 内容 |
| --- | --- |
| 受影响角色 | 已登录学生；公开读取无需登录 |
| 前置条件 | `VULN_MODE=ALL` 或 `VULN-04`；上传目录可写 |
| 成因 | 跳过 MIME/扩展名/magic bytes 校验，保留原始文件名；新增无认证公开读取 `/api/v1/uploads-public/:id`，按存储 MIME 返回 |
| 预期影响 | 上传 `.html` 等可执行内容并可被公开访问，形成同源脚本执行/内容托管；同名上传覆盖文件；存储滥用 |
| 检测方法 | 上传 `text/html` 测试文件 → 201；无令牌访问公开读取 → 200 `text/html`；浏览器打开可执行脚本标记；同名上传检查文件内容被替换 |
| 修复建议 | 白名单 + magic bytes；服务端重命名；禁止可执行扩展名；上传目录不在 Web 根；公开读取必须鉴权；独立域名/CSP；大小/配额；病毒扫描 |
| 当前状态 | 已验证：ALL 上传 201、公开读取 200、文本内容可执行；同名覆盖成立；off 415 |

### VULN-05 · 登录失败限流失效

| 项 | 内容 |
| --- | --- |
| 受影响角色 | 未认证攻击者 |
| 前置条件 | `VULN_MODE=ALL` 或 `VULN-05`；目标账号存在 |
| 成因 | ALL/VULN-05 时跳过登录失败计数与限流检查 |
| 预期影响 | 可无限次尝试口令，便于暴力破解/撞库 |
| 检测方法 | 连续失败登录：off 第 11 次 429；ALL 连续 15 次均 401 |
| 修复建议 | 失败限流/锁定；IP+账号维度；验证码/MFA；告警 |
| 当前状态 | 已验证：off 第 11 次 429；ALL 15 次均 401 |

## 4. 验证步骤与判定（高层）

> 不提供完整攻击载荷；以下为操作类别与判定点。

### 4.1 VULN-01

1. 基线：正常用户名 + 错误密码 → 401 `AUTH_INVALID_CREDENTIALS`。
2. 注入型登录名 + 任意密码 → 200，`data.user.role=admin`。
3. 正常用户名 + 正确密码 → 200（回归正常登录）。
4. 判定：步骤 2 成功即存在；步骤 1 仍 401 说明未破坏正常失败路径。

### 4.2 VULN-02

1. 学生写入带事件属性的描述；观察 API 返回原样包含 HTML。
2. 另一账号打开详情页；用浏览器控制台标记（如 `window` 标记）判断是否执行。
3. `off` 模式下同样写入应被转义；详情页不执行。
4. 判定：ALL 下标记为真即存在；off 下不执行为基线正确。

### 4.3 VULN-03

1. 学生令牌 PATCH admin 的条目（如 id=5）。
2. `off` → 403；`ALL`/VULN-03 → 200，且响应 owner 仍为 admin。
3. 判定：200 即越权；记录修改前后字段，验证后重置。

### 4.4 VULN-04

1. `off`：上传 `text/html` → 415。
2. `ALL`：上传 `text/html` → 201，`mimeType=text/html`，文件名保留。
3. 无令牌访问 `/api/v1/uploads-public/{id}` → 200，`Content-Type: text/html`，响应体包含测试内容；浏览器打开时脚本可执行。
4. 同名再次上传 → 文件内容被覆盖（可用 `docker exec`/存储检查）。
5. 判定：公开读取 200 + `text/html` + 脚本执行即完整命中；记录路径、文件 id、清理。

### 4.5 VULN-05

1. `off`：连续失败登录，第 11 次 429 `RATE_LIMITED`。
2. `ALL`：连续 15 次失败均 401，无 429。
3. 判定：ALL 下无 429 即存在；记录状态码序列。

## 5. 证据与清理

- 证据：请求/响应（脱敏 token）、浏览器截图/DOM 标记、服务端日志、必要的数据计数；不记录密码/完整 token/真实 IP。
- 清理：
  1. 删除测试条目/上传文件；
  2. `VULN_MODE=off` 或停止全量实例；
  3. 重置演示数据（`bash scripts/seed.sh`，仅 MySQL）；
  4. 删除测试账号（如创建）；
  5. 确认无公开上传文件残留。
- 回归：修复后按同一用例复测；确认正常登录/正常上传/正常权限仍可用。

## 7. 风险与边界

- 本实例默认**全量漏洞开启**，仅限课程内部使用；不得公网长期开放给非课程人员。
- `main` 仍是安全基线；漏洞代码不得合并 `main`。
- VULN-01/04 已达到设计目标，但也意味着风险显著高于单漏洞模式；测试后应恢复 `off` 或停止实例。
- 详细风险应对见课程本地《风险应对预案》（不进入仓库）。
