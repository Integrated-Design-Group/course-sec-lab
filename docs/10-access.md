## 2. 测试账号发放与回收

### 2.1 发放规则

| 规则 | 说明 |
| --- | --- |
| 账号隔离（一人一号） | 每个参与者使用独立测试账号，便于审计追踪；创建方式见 [15-vuln-test-accounts.md](./15-vuln-test-accounts.md) |
| 角色最小化 | 验证学生场景发 `student`；验证管理场景才发 `admin` |
| 密码强度 | 至少 12 位、包含大小写/数字/符号；**不使用** `Demo@123456`；脚本强制校验 |
| 传递方式 | 课程平台私信或加密渠道；禁止群聊明文、禁止写入仓库 |
| 有效期 | 绑定测试窗口；窗口结束即停用 |
| 记录 | 只登记“账号代号 + 角色 + 领取人 + 日期”，不登记密码 |

### 2.3 回收流程

1. 测试窗口结束后，把账号 `status` 置为 `disabled`（或删除）。
2. 重置数据库与上传目录（`bash scripts/seed.sh`）。
3. 轮换数据库密码与 `JWT_SECRET`（若曾经暴露）。
4. 在登记表填写停用日期，并在变更记录中登记。
