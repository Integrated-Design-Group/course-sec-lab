# 00 · 项目总览与范围

> **适用对象**：课程小组成员、指导教师、验收人
> **前置条件**：已阅读课程要求；本地具备 Node.js 22+（或 Docker）
> **预计耗时**：阅读 10 分钟

## 1. 这是什么

**course-sec-lab（课程 Web 安全靶场）** 是一个课程小组自主设计的 Web 管理系统，本仓库当前处于 **框架阶段（M0）**。

- 业务场景：**校园二手教材交易平台**——学生发布闲置教材/笔记，管理员维护平台内容。
- 当前交付：工程骨架、数据库结构、前后端 API 契约、部署架构、文档规范、模板与最小可运行链路。
- 明确不交付：完整业务 CRUD、真实漏洞、云服务器实例、真实公网地址。

## 2. 为什么选择这个业务场景

| 维度 | 说明 |
| --- | --- |
| 业务真实 | 校园二手交易是学生熟悉的真实场景，答辩时容易讲清“谁在用、解决什么问题” |
| 结构完整 | 天然包含用户、角色、资源（条目）、文件（封面图）、审计（操作记录） |
| 漏洞可设计 | 登录、列表筛选、详情、上传等入口可以自然映射到 3～5 类典型 Web 漏洞 |
| 数据可脱敏 | 全部使用假数据，不涉及真实学生个人信息与支付信息 |
| 范围可控 | 业务模型简单，能在课程周期内完成“框架 → 业务 → 漏洞 → 部署 → 验证”闭环 |

## 4. 技术栈（框架阶段选定）

| 层 | 选型 | 版本 | 说明 |
| --- | --- | --- | --- |
| 运行时 | Node.js | 22.14.0（LTS） | 容器镜像固定；本机验证使用 v24.18.0（满足 engines >= 22） |
| 后端 | Express | 4.21.2 | 稳定、生态成熟，适合教学拆解中间件 |
| 数据库 | MySQL | 8.4.4 | 需要 8.0.19+（种子脚本使用 `INSERT ... AS new` 语法） |
| 前端 | React + Vite | 18.3.1 / 5.4.11 | 构建快、结构简单 |
| 反向代理 | Nginx | 1.27.4-alpine | 静态资源 + `/api` 反代 |
| 编排 | Docker Compose | Compose v2 | 一键拉起 web / backend / db |

版本锁定、启动命令、端口与日志路径见 [05-environment.md](./05-environment.md)。

## 5. 框架阶段的边界（F0）

### 5.1 本阶段完成

- 目录与工程骨架、依赖锁定、环境变量模板
- 数据库：`roles`、`users`、`business_items`、`uploaded_files`、`audit_logs` 表 + 迁移 + 种子
- 后端：配置校验、统一响应、错误码、结构化日志、健康检查、认证闭环、只读业务接口、安全上传基线
- 前端：路由、布局、登录页、API Client、路由守卫、健康检查展示
- 部署：Compose 编排、Nginx 配置、部署/回滚脚本**占位**
- 文档：架构、数据库、API、部署、环境、规范、隔离、漏洞模板、验证模板、访问登记、验收清单

### 5.2 本阶段明确不做

- 不实现完整业务 CRUD（新增/编辑/删除只返回 `501 NOT_IMPLEMENTED`）
- 不实现任何漏洞：**没有** SQL 注入、XSS、越权、不安全文件上传、弱认证等可利用缺陷
- 不创建云服务器、不绑定域名、不配置真实安全组、不执行 `git push`
- 不写入真实密码、云密钥、证书私钥或任何敏感数据
- 不做性能压测、不做多副本高可用（单机课程版）

> 漏洞的**设计**在 [08-vuln-design.md](./08-vuln-design.md) 中规划（VULN-01～VULN-05），实现必须留到独立分支、独立环境，并遵循 [07-security-isolation.md](./07-security-isolation.md)。

## 7. 关键约定（全项目）

1. **API 前缀固定** `/api/v1`；成功/失败都使用统一响应信封（见 [03-api.md](./03-api.md)）。
2. **时间统一存 UTC**（数据库 `DATETIME(3)`，API 返回 ISO 8601），前端按本地时区展示。
3. **密钥只进 `.env`**；`.env.example` 只放占位符。仓库内出现真实密钥即视为不合格。
4. **演示账号** `admin` / `student`，密码 `Demo@123456`，仅课程环境使用，公网部署前必须改密或停用。
5. **框架阶段所有“未实现”必须显式失败**（501 / 404），不允许返回假的成功结果。

## 9. 安全与合规声明

本靶场**只用于课程授权范围内的安全测试**：

- 必须独立部署，不得与真实业务系统共用主机、数据库、域名或账号；
- 存放的数据必须是课程假数据，不得导入真实个人信息；
- 任何测试必须在约定时间窗口、约定来源 IP 内进行；
- 未获得课程负责人书面（含课程平台）授权，不得对任何非本项目目标进行测试。
