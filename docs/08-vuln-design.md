## 6. 开关设计建议

```text
# .env（仅靶场实例使用，禁止出现在 main 分支的部署配置中）
VULN_MODE=off            # off | VULN-01 | VULN-02 | ...
```

要求：

- 默认 `off`；非 `off` 时启动日志打印醒目警告，健康检查返回中也标注当前模式。
- 同一实例同一时刻只开启一个漏洞，避免实验相互干扰。
- 开关只影响后端行为，前端不感知，避免“按开关写死判断”的假漏洞。

## 7. 明确禁止

1. 禁止在 `main` 分支或框架演示实例中实现漏洞。
2. 禁止把漏洞代码、利用载荷、真实目标地址提交到仓库或公开渠道。
3. 禁止对课程之外的任何系统进行测试。
4. 禁止使用真实个人信息、真实凭据进行验证。
5. 禁止在验证中使用拒绝服务、批量拖库、持久化后门等超出课程授权的手段。
6. 禁止在未备份的情况下执行可能破坏数据的验证。
